## 📖 项目简介

本项目不依赖任何前端框架，纯手工编写语义化 HTML 标签与 CSS 样式，高精度像素级还原京东 PC 端首页复杂布局。

### 涵盖知识点：
- 复杂顶部快捷导航栏、搜索框与购物车下拉交互
- 多级分类浮动抽屉与轮播 Banner 布局
- 京东秒杀倒计时倒三角模块设计
- 标准 CSS Sprite 雪碧图定位与减少 HTTP 请求实战
